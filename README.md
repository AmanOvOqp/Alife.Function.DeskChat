# Alife.Function.DeskChat (桌面透视聊天框)

常驻屏幕边缘的半透明极简聊天框，专为无需完整桌宠身躯的纯文字交互场景打造。

## 特性亮点
- **极简透明磨砂设计**：仅占用屏幕小角落，毛玻璃现代质感，美观不遮挡工作区。
- **智能鼠标穿透**：默认对鼠标完全透明，不影响游戏、网页与文档操作。
- **悬停自动唤醒**：当光标移入输入框区域时毫秒级切回交互模式，移开后恢复穿透。
- **即插即用**：零额外大模型依赖，直接与当前激活的 AI 对话。

## 配置项
- `WindowWidth`: 窗口宽度（默认 320）
- `WindowHeight`: 窗口高度（默认 120）
- `EnableMouseThrough`: 鼠标穿透开关（默认开启）
- `Placeholder`: 输入框提示文本
